# Central de Urgência Acessível

Projeto acadêmico com foco em acessibilidade e inclusão, pensado para apresentar informações visuais e orientações úteis a pessoas surdas em situações de urgência.

## Objetivo

Facilitar o acesso à informação por meio de páginas simples, textos objetivos, navegação clara e recursos visuais. O projeto destaca a importância de meios de comunicação acessíveis, como Libras e mensagens escritas.

## Páginas implementadas

- `index.html`: apresentação do projeto e acesso às principais áreas.
- `libras.html`: orientações sobre comunicação acessível e solicitação de apoio em Libras.
- `orientacoes.html`: orientações gerais para buscar ajuda e compartilhar localização.

## Tecnologias

- HTML5: estrutura e organização do conteúdo.
- CSS3: identidade visual, layout responsivo, cores e acessibilidade.

## Estrutura de pastas

## Paleta de cores

| Cor | Código HEX | Aplicação |
|---|---|---|
| Azul-marinho | `#102A43` | Cabeçalho, rodapé e títulos |
| Azul | `#1769AA` | Destaques, links e elementos de navegação |
| Azul-claro | `#EAF4FC` | Fundos de áreas informativas |
| Vermelho | `#C93636` | Alertas e destaque de urgência |
| Verde | `#18794E` | Elementos de orientação positiva |
| Branco | `#FFFFFF` | Fundo dos cartões e contraste |

### Justificativa da paleta

O azul transmite confiança e organização e é utilizado como cor principal da identidade visual. O vermelho destaca avisos importantes relacionados à urgência. O verde identifica informações de orientação. O branco e os fundos claros ajudam a manter a leitura confortável. A combinação foi escolhida para criar contraste entre texto e fundo e facilitar a identificação visual das seções.

## Acessibilidade considerada

- Idioma da página definido como português do Brasil.
- Estrutura semântica com cabeçalho, navegação, conteúdo principal e rodapé.
- Link para pular diretamente ao conteúdo.
- Navegação por teclado com indicação de foco.
- Layout adaptável a telas menores.
- Conteúdo apresentado em texto, sem depender de áudio.
- Respeito à preferência do sistema por movimento reduzido.

## Como visualizar

Abra o arquivo `index.html` em um navegador. Para publicar, envie todos os arquivos mantendo a estrutura de pastas para o mesmo repositório GitHub Pages.

## Limitações desta versão

Esta versão é informativa e acadêmica. Ela não envia chamados de emergência, não rastreia GPS, não conecta automaticamente com serviços públicos e não oferece interpretação em Libras em tempo real. Esses recursos exigiriam integração com serviços e parceiros reais, além de testes e validação.

## Publicação no GitHub Pages

1. Envie os arquivos para o repositório do projeto.
2. Confirme que `index.html` está na raiz do repositório.
3. Em **Settings > Pages**, selecione a branch utilizada e a pasta `/ (root)`.
4. Salve e aguarde a publicação.
5. Abra o endereço do GitHub Pages e teste os links e a visualização no celular.
